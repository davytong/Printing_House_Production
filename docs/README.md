## 📝 Documentation Standards

All documentation files in this folder should follow these standards:

1. **File naming**: Use `UPPERCASE_WITH_UNDERSCORES.md` format
2. **Structure**: Include date, summary, technical details, and examples
3. **Language**: Technical content in English, UI examples in Khmer/English
4. **Updates**: Keep documentation updated when features change
