# របៀបកែប្រែ Category Labels (How to Edit Category Labels)

## ជំហានទី 1: ចូលទៅកាន់ Telegram Setup
1. បើក application
2. ចុចលើ **Telegram** ក្នុង navigation menu
3. រកឃើញផ្ទាំង **"កែប្រែ Category Labels"**

## ជំហានទី 2: កែប្រែ Labels
អ្នកនឹងឃើញ 3 input fields:

### 📄 Paper Label
- លំនាំដើម: `ក្រដាស (Paper)`
- ឧទាហរណ៍: អ្នកអាចប្តូរទៅជា `ក្រដាសបោះពុម្ព` ឬឈ្មោះផ្សេងទៀត

### 🎞️ Film Label
- លំនាំដើម: `Film (ហ្វីម)`
- ឧទាហរណ៍: អ្នកអាចប្តូរទៅជា `Laminate Film` ឬ `ហ្វីម Laminate`

### 🧴 Consumable Label
- លំនាំដើម: `Consumable (សម្ភារៈប្រើប្រាស់)`
- ឧទាហរណ៍: អ្នកអាចប្តូរទៅជា `សម្ភារៈផ្សេងៗ` ឬឈ្មោះផ្សេងទៀត

## ជំហានទី 3: រក្សាទុក
1. បន្ទាប់ពីកែប្រែរួច ចុច **"រក្សាទុក Labels"**
2. អ្នកនឹងឃើញសារ success: "បានរក្សាទុក Category Labels!"
3. Label ថ្មីនឹងប្រើភ្លាមៗក្នុង Daily Report ទាំងអស់

## ឧទាហរណ៍ការប្រើប្រាស់

### មុនពេលកែប្រែ
```
🎞️ Film (ហ្វីម) នៅសល់មានចំនួន:
- Glossy Film — ហ្វីមរលោង : 9 roll
- Matte Film — ហ្វីមម៉ាត់ : 37 roll
#Film_Stock
```

### បន្ទាប់ពីប្តូរ Film Label ទៅជា "Laminate Film"
```
🎞️ Laminate Film នៅសល់មានចំនួន:
- Glossy Film — ហ្វីមរលោង : 9 roll
- Matte Film — ហ្វីមម៉ាត់ : 37 roll
#Film_Stock
```

## ត្រឡប់ទៅលំនាំដើម (Reset)

ប្រសិនបើអ្នកចង់ត្រឡប់ទៅ labels លំនាំដើម:
1. ចុចប៊ូតុង **"លំនាំដើម (Reset)"** (ពណ៌ក្រហម)
2. បញ្ជាក់ការ reset
3. Labels ទាំងអស់នឹងត្រឡប់ទៅតម្លៃដើម

## ចំណាំសំខាន់ៗ

✅ **ប្រើបានភ្លាម**: ការផ្លាស់ប្តូរនឹងប្រើភ្លាមៗ មិនចាំបាច់ restart server

✅ **គ្រប់ Category**: កែប្រែបានទាំង Paper, Film, និង Consumable

✅ **Bilingual**: អ្នកអាចប្រើភាសាខ្មែរ អង់គ្លេស ឬលាយគ្នា

✅ **រក្សាសុវត្ថិភាព**: មាន Reset button ប្រសិនបើមានកំហុស

✅ **កែប្រើបានជាញឹកញាប់**: អ្នកអាចកែប្រែពេលណាក៏បាន

## ផ្ទៀងផ្ទាត់ការផ្លាស់ប្តូរ

បន្ទាប់ពីកែប្រែ labels:
1. ចូលទៅកាន់ **Stock → Daily Update**
2. ជ្រើសរើស category ណាមួយ
3. បំពេញទិន្នន័យ Stock
4. ផ្ញើ Telegram report
5. ពិនិត្យមើលក្នុង Telegram → labels ថ្មីនឹងបង្ហាញ

## English Version

### Step 1: Go to Telegram Setup
1. Open the application
2. Click **Telegram** in navigation menu
3. Find **"កែប្រែ Category Labels"** panel

### Step 2: Edit Labels
You will see 3 input fields:

**📄 Paper Label**
- Default: `ក្រដាស (Paper)`
- Example: Change to `Printing Paper` or any name you want

**🎞️ Film Label**
- Default: `Film (ហ្វីម)`
- Example: Change to `Laminate Film` or `Film Laminate`

**🧴 Consumable Label**
- Default: `Consumable (សម្ភារៈប្រើប្រាស់)`
- Example: Change to `Supplies` or any name you want

### Step 3: Save
1. After editing, click **"រក្សាទុក Labels"** (Save Labels)
2. You will see success message
3. New labels will be used immediately in all Daily Reports

### Reset to Defaults
1. Click **"លំនាំដើម (Reset)"** button (red)
2. Confirm the reset
3. All labels will return to default values

### Important Notes
✅ Changes apply immediately
✅ All categories editable
✅ Supports bilingual text
✅ Safe to experiment (Reset available)
✅ Can change anytime you want
