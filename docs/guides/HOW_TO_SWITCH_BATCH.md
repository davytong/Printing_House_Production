# 🔄 How to Switch Back to Batch 1 (Old Batch)

## Simple Step-by-Step Guide

---

## Current Situation:
- ✅ **Batch 2** is active (you're working on this now)
- ⏸ **Batch 1** is suspended at 70% (you want to go back to this)

---

## Steps to Switch to Batch 1:

### Step 1: Go to Printing Page
Navigate to: **`/printing`** page (ការបោះពុម្ព)

---

### Step 2: Look at the Top Right Corner

You'll see these buttons:

```
[Export]  [🔵 Batch 2 (active)]  [⏱️ ប្រវត្តិ Batch ▼]  [+ ចាប់ផ្ដើម Batch ថ្មី]
```

---

### Step 3: Click "ប្រវត្តិ Batch" Button

This button has a **clock icon** ⏱️ and means "Batch History"

---

### Step 4: Dropdown Menu Appears

You'll see a dropdown menu like this:

```
┌────────────────────────────────────────────┐
│  អតីតកាល Batches — ចុច Switch ដើម្បីត្រឡប់  │
├────────────────────────────────────────────┤
│  ⏸ Batch 1                    [Switch] [🗑]│
│     Suspended                              │
└────────────────────────────────────────────┘
```

---

### Step 5: Click "Switch" Button Next to Batch 1

Click the **green [Switch]** button (NOT the red trash button!)

---

### Step 6: Confirm the Switch

A confirmation dialog appears:

```
ប្ដូរទៅ Batch 1? Batch បច្ចុប្បន្ននឹងត្រូវរក្សាទុក។
(Switch to Batch 1? Current batch will be saved.)

[Cancel]  [OK]
```

Click **[OK]**

---

### Step 7: Done! ✅

Now:
- ✅ **Batch 1** is active (you can continue from 70%)
- ⏸ **Batch 2** is suspended (saved at 3%, can resume later)

---

## Quick Reference

| What | Where | Action |
|------|-------|--------|
| **Go to** | `/printing` page | Navigate |
| **Click** | "ប្រវត្តិ Batch" button | Opens dropdown |
| **Find** | ⏸ Batch 1 Suspended | In dropdown list |
| **Click** | [Switch] button | Green button |
| **Confirm** | Click [OK] | Confirm dialog |
| **Result** | Batch 1 is now active | You can work on it |

---

## Important Notes:

✅ **Safe**: Your Batch 2 progress (3%) is automatically saved
✅ **Reversible**: You can switch back to Batch 2 anytime (same steps)
✅ **No data loss**: All your printing records are preserved
⚠️ **Don't click**: The red [🗑] Delete button (unless you want to permanently delete)

---

## To Switch Back to Batch 2 Later:

Same steps, but choose Batch 2 from the dropdown:

1. Click "ប្រវត្តិ Batch"
2. Find ⏸ Batch 2
3. Click [Switch]
4. Confirm [OK]

---

## Troubleshooting

### "I don't see the ប្រវត្តិ Batch button"
**Solution**: Refresh the page (Ctrl+R). The button should appear next to "Batch 2 (active)".

### "Batch 1 doesn't appear in the dropdown"
**Solution**: 
- First, refresh the page: `Ctrl+Shift+R` (hard refresh)
- If still not showing, Batch 1 might be set as "pending" or "active" (check dashboard)

### "I accidentally clicked Delete"
**Solution**: If you confirmed deletion, the batch is permanently lost. If you haven't confirmed, click [Cancel].
