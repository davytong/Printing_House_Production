The language switcher is in the **top-right corner** of every page, next to the notification bell.

## 📱 Mobile Display

On mobile phones (screen width < 640px), the language switcher becomes:

```
Desktop: 🇰🇭 ខ្មែរ  |  🇬🇧 EN
Mobile:  🇰🇭      |  🇬🇧
```

The text is hidden to save space, showing only the flag icons.

## How to Switch Languages

### Step 1: Look at Top-Right Corner
You'll see two buttons:
- 🇰🇭 ខ្មែរ (Khmer mode - bilingual)
- 🇬🇧 EN (English mode - English only)

### Step 2: Click Your Preference
- **Click 🇰🇭 ខ្មែរ** → Shows "ខ្មែរ — English" format (bilingual)
- **Click 🇬🇧 EN** → Shows "English" only

### Step 3: See Changes Immediately
- The active button turns **blue** with white text
- The inactive button is **gray**
- All menu items change format instantly
- Your choice is saved in your session

## 🔄 How It Works

1. **You click a language button** → Route: `/lang/km` or `/lang/en`
2. **System saves your choice** → Stored in session
3. **Page reloads** → Shows content in chosen language
4. **Choice persists** → Stays the same as you navigate
5. **Even after refresh** → Your preference is remembered
