# របៀបបន្ថែមឯកសារភ្ជាប់ទៅ PO (How to Add Attachments to Purchase Orders)

## ជំហានសម្រាប់បន្ថែមឯកសារ

### ជំហានទី 1: បើក Purchase Order
1. ចូលទៅ **Purchase Orders** menu
2. រកឃើញ PO ដែលចង់បន្ថែមឯកសារ
3. ចុចលើ PO Number ដើម្បីបើក detail page

### ជំហានទី 2: រកឃើញផ្នែកបន្ថែមឯកសារ
- Scroll ចុះក្រោម ទៅ bottom of page
- រកឃើញផ្នែក **"បន្ថែមឯកសារភ្ជាប់ថ្មី"** (Add New Attachments)
- ផ្នែកនេះមានគ្រប់ពេល ទោះបីជា PO ត្រូវបាន **received** រួចក៏ដោយ ✅

### ជំហានទី 3: ជ្រើសរើសឯកសារ
1. ចុចប៊ូតុង **"ជ្រើសរើសឯកសារ"** (Choose Files)
2. រកឃើញឯកសារនៅ computer/phone របស់អ្នក
3. អ្នកអាចជ្រើសរើសបានច្រើនឯកសារក្នុងពេលតែមួយ (អតិបរមា 10)

**ប្រភេទឯកសារដែលអាចប្រើបាន:**
- 🖼️ រូបភាព: JPG, PNG, GIF, WebP
- 📄 PDF documents
- 📝 Word: DOC, DOCX
- 📊 Excel: XLS, XLSX

**ទំហំអតិបរមា:** 10MB per file

### ជំហានទី 4: Upload
1. បន្ទាប់ពីជ្រើសរើសឯកសាររួច
2. ចុចប៊ូតុង **"បន្ថែមឯកសារ (Upload)"**
3. រង់ចាំឯកសារ upload រួច
4. អ្នកនឹងឃើញសារ: "បានបន្ថែមឯកសារ X ទៅកាន់ PO XXX"

### ជំហានទី 5: ពិនិត្យមើលឯកសារ
- ឯកសារដែល upload រួចនឹងបង្ហាញនៅផ្នែក **"ឯកសារភ្ជាប់"**
- មានព័ត៌មាន:
  - ឈ្មោះឯកសារ
  - ទំហំ (KB)
  - ថ្ងៃខែឆ្នាំ upload
  - ប៊ូតុង View (👁️) និង Delete (🗑️)

## របៀបមើលឯកសារ

1. រកឃើញឯកសារនៅផ្នែក "ឯកសារភ្ជាប់"
2. ចុចលើ icon **👁️** (Eye icon)
3. ឯកសារនឹងបើកក្នុង tab ថ្មី
4. អ្នកអាចទាញយក (download) ឬ print បាន

## របៀបលុបឯកសារ

⚠️ **ប្រយ័ត្ន**: ការលុបមិនអាចយកត្រឡប់មកវិញបានទេ!

1. រកឃើញឯកសារដែលចង់លុប
2. ចុចលើ icon **🗑️** (Trash icon)
3. បញ្ជាក់ការលុប: "លុបឯកសារនេះ?"
4. ចុច OK
5. ឯកសារនឹងត្រូវលុបចេញពី system

## ឧទាហរណ៍ការប្រើប្រាស់

### Example 1: បន្ថែម Invoice
```
Scenario: PO ត្រូវបាន received រួច តែ invoice មកពេលក្រោយ

✅ Solution:
1. បើក PO detail page
2. Upload រូបថត invoice ឬ PDF
3. Invoice នឹងត្រូវ attach ជាមួយ PO
4. អាចមើលវិញនៅពេលណាក៏បាន
```

### Example 2: ថតរូបទំនិញដែលទទួល
```
Scenario: ចង់រក្សាទុករូបភាពទំនិញដែលទទួលបាន

✅ Solution:
1. ថតរូបទំនិញដោយ phone
2. បើក PO page នៅលើ phone
3. Upload រូបភាពច្រើន at once
4. រូបភាពទាំងអស់នឹងត្រូវ save ជាមួយ timestamp
```

### Example 3: បន្ថែមឯកសារផ្សេងៗ
```
អ្វីដែលអាច attach:
✅ Invoice ពី supplier
✅ Delivery note
✅ រូបថត packaging
✅ Quality inspection report
✅ Email confirmation
✅ Certificate of quality
✅ Test reports
```

## ចំណាំសំខាន់ៗ

✅ **អាចបន្ថែមពេលណាក៏បាន**: ទោះបីជា PO ត្រូវបាន received រួច

✅ **Upload ច្រើនឯកសារ**: សន្សំពេលវេលាដោយ upload តែម្តង

✅ **មានកាលបរិច្ឆេទ**: ឯកសារទាំងអស់មាន timestamp

✅ **មើល និង ទាញយកបាន**: ចុច view icon ដើម្បីមើល

✅ **លុបបានប្រសិនចាំបាច់**: លុបឯកសារខុសដោយមានការបញ្ជាក់

❌ **មិនអាច undo**: ការលុបមិនអាចយកត្រឡប់មកវិញ

## Tips & Tricks

💡 **ប្រើឈ្មោះឯកសារច្បាស់លាស់**
- ប្រសើរ: `invoice_supplier_2026-06-27.pdf`
- មិនប្រសើរ: `IMG_001.jpg`

💡 **Upload លំដាប់ល្អ**
- Invoice ជាមុនសិន
- Delivery note
- រូបភាពបន្ទាប់ពីនោះ

💡 **រក្សាទុកទាំងអស់**
- កុំលុបឯកសារចាស់ លុះត្រាតែខុស
- រក្សាទុក complete documentation

💡 **Scan ជា PDF**
- ប្រសើរជាង phone photos សម្រាប់ documents
- ងាយស្រួលអាន និង print

## ការដោះស្រាយបញ្ហា

### បញ្ហា: Upload មិនដំណើរការ
**ដំណោះស្រាយ:**
- ពិនិត្យទំហំឯកសារ (max 10MB)
- ពិនិត្យប្រភេទឯកសារ (JPG, PNG, PDF, DOC, XLS)
- ពិនិត្យ internet connection
- Refresh page ហើយព្យាយាមម្តងទៀត

### បញ្ហា: មិនឃើញ upload button
**ដំណោះស្រាយ:**
- Scroll ចុះ bottom of page
- Refresh page
- Clear browser cache

### បញ្ហា: File too large
**ដំណោះស្រាយ:**
- Compress រូបភាព (ប្រើ app compress)
- Split PDF ធំៗ ជា files តូចៗ
- Upload ម្តងមួយ file

## English Quick Guide

### How to Add Attachments

1. **Open PO**: Navigate to Purchase Orders → Click on PO Number
2. **Find Upload Section**: Scroll to bottom → "បន្ថែមឯកសារភ្ជាប់ថ្មី" section
3. **Select Files**: Click "Choose Files" → Select up to 10 files
4. **Upload**: Click "បន្ថែមឯកសារ (Upload)" button
5. **Done**: Files appear in "ឯកសារភ្ជាប់" section with timestamps

### Supported Files
- Images: JPG, PNG, GIF, WebP
- Documents: PDF, DOC, DOCX, XLS, XLSX
- Max size: 10MB per file
- Max count: 10 files per upload

### Key Features
✅ Works even after PO is received
✅ Multiple files at once
✅ View and delete individual files
✅ Automatic timestamps
✅ No restrictions by PO status
