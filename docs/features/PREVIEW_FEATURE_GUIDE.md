# 👁️ Preview Report Feature - User Guide

## Overview

The Preview feature allows you to see exactly what the daily report will look like before copying or sending it.

---

## 🎯 How to Use

### Step 1: Open Report Page
```
Navigate to: /report (របាយការណ៍)
```

### Step 2: Click Preview Button
```
┌────────────────────────────────────────────────┐
│  [👁️ Preview] [📋 Copy] [📱 Telegram] [←]    │
└────────────────────────────────────────────────┘
```

Click the **"👁️ Preview Report"** button

### Step 3: See the Modal
```
┌──────────────────────────────────────────────┐
│  👁️ Preview របាយការណ៍ប្រចាំថ្ងៃ          │   ×
├──────────────────────────────────────────────┤
│                                              │
│  [📄 Full Format]  [📱 Compact Format ✓]    │
│                                              │
│  ┌────────────────────────────────────────┐ │
│  │ 📊 របាយការណ៍ប្រចាំថ្ងៃ - 27/06/2026 │ │
│  │ Batch: Batch 2                         │ │
│  │                                        │ │
│  │ Pre School 5: 820/7,000 (12%)         │ │
│  │   • Writing Textbook: +420            │ │
│  │                                        │ │
│  │ ━━━━━━━━━━━━━━━━━━                   │ │
│  │ 📈 សរុប: 820 ក្បាល                   │ │
│  │ 💪 ថ្ងៃនេះ: +420 ក្បាល               │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  [បិទ]  [📋 Copy Report]                    │
└──────────────────────────────────────────────┘
```

### Step 4: Switch Formats
- Click **"📄 Full Format"** - See detailed formal report
- Click **"📱 Compact Format"** - See short Telegram version

### Step 5: Copy from Preview
Click **"Copy Report"** button in modal → Copied to clipboard!

## 🎨 Features

### 1. **Live Loading**
- Shows loading spinner while fetching
- Real-time data from database
- Always up-to-date

### 2. **Format Toggle**
- Switch between formats instantly
- No page reload needed
- Compare side-by-side

### 3. **Easy Copy**
- Copy button in preview
- Or use main "Copy Report" button
- Automatic clipboard copy

### 4. **Scrollable View**
- Long reports scroll in modal
- Fixed height with scrollbar
- Easy to read

### 5. **Monospace Font**
- Perfect Unicode alignment
- Box drawings display correctly
- Clean, readable format

3. Review all sections

```

4. Compare both
5. Choose best for audience
6. Copy chosen format
```

## 🔧 Technical Details

### Modal Specs:
- **Size**: Large (modal-lg)
- **Auto-load**: Compact format on open
- **Scrollable**: Max height 500px
- **Font**: Monospace for alignment
- **Background**: Light gray (#f8f9fa)

### API Call:
```javascript
GET /report/daily?date=2026-06-27&format=compact
```

### Response:
```json
{
  "success": true,
  "report": "📊 របាយការណ៍...",
  "date": "2026-06-27"
}
```

## 🔍 What You See

### Preview Content Shows:
✅ Exact text that will be copied
✅ All Unicode characters
✅ Box drawings (━ │ ┌ ┐)
✅ Khmer numerals
✅ Emoji icons
✅ Proper spacing/alignment

### Preview Does NOT Show:
❌ HTML formatting
❌ Colors (plain text only)
❌ Interactive elements
❌ Images/attachments
